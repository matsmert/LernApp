# LernApp

Vibe-Coded!

Multiple-Choice-Lern-App im Fahrschul-Stil: Kapitel lernen, bis alles auf 100 % steht – mit Hugo, dem Lern-Hippo.

**App öffnen:** https://matsmert.github.io/LernApp/

## Aufs iPhone
1. Link oben in **Safari** öffnen.
2. Teilen-Symbol → **Zum Home-Bildschirm**.
3. Die App startet dann im Vollbild und funktioniert auch offline.

## Module laden
„Modul hinzufügen“ → **Aus Datei** (z. B. eine `.lernmodul`-Datei aus iCloud Drive) oder **Per Prompt** (eine KI erstellt das Modul aus deinen Folien, die Antwort fügst du in der App ein).

Module und Lernfortschritt bleiben nur auf deinem Gerät – in diesem Repository liegt nur die leere App.

## Sync zwischen Geräten
Unten auf der Startseite: **Sichern** → „In Dateien sichern“ → iCloud Drive (alte Datei ersetzen).
Auf dem anderen Gerät: **Laden** → Datei aus iCloud Drive wählen. Beide Stände werden zusammengeführt, nichts geht verloren.
